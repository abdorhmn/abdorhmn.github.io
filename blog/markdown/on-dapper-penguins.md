## baby's first linux distro
My introduction to Linux was about 3 years ago when a robotics mentor was breathing life back into this old computer we had lying around the shop and showed me how to install [Ubuntu](http://ubuntu.com/). I got to mess around with it a bunch, tried some ==FOSS==[^1] applications. A personal favorite is [*SuperTuxKart*](https://supertuxkart.net/), which, while not the most productive, is a blast to play. This is all thanks to its fun game play which shines through the aging graphics. It’s got all these fun open source characters that are all [mascots](https://pclosmag.com/html/Issues/202407/page07.html) of different pieces of software, and a bunch of different game modes.

## the first goal
Very first thing I did after that was try to emulate some games. That didn’t work… I ran into some issues trying to get the emulation software to run since it was made for windows, but using ==WINE==[^2] it wasn’t too bad. The difficult part was once I actually got everything setup, the fact that the game just wouldn’t get past the first loading screen. It’s possible that I needed something else beside the emulator it to get it to work, but I decided to chalk it up to the computer being woefully under spec-ed for what I was putting it through. I then played around with Ubuntu’s flavor of ==[Gnome](https://www.gnome.org/)==[^3] customizing things until I felt like I got the ropes of the computer. I ended up leaving the computer sitting there for a while. I enjoyed the experience messing with it, but I didn’t really know what I was intending to get out of it.

## 3 years later...
I thought about switching to some sort of Linux distribution, but the thought of what would be the point of all that trouble kept coming up. It didn’t feel like I was really learning all that much. Then I went to uni, and I met ==a lot==[^4] of people who were using Linux, piquing my curiosity.

Why Linux? What was so cool about Linux? Would I benefit from using Linux? Would I become the ultimate computer user if I used Linux?

“Uhm… I don’t know? It’s an operating system.” was the most common sentiment I got. Think about that. Like Windows or MacOS, it’s an operating system. Not some fantastical tool, or magic entity, but an operating system. Which made me think about it a little differently. In my life, this is would be the equivalent of Windows. The neat part is it’s not owned by Microsoft, *and* it’s free and open source.

The reason that this is cool is ***Control***. What is the point of an operating system? It’s to let you use software you want to use to do something. That can be accessing the *interwebs* to get work done, playing a game, programming, simulation software, consuming media, or really anything. With so many things being done on your computer, you’d think you would be able to control how you could do those things.

So, with Linux, the idea is that you are in control of you experience, and you are no longer the product that Microsoft is making money off of, thus there is no ==fall off in quality for the sake of profit==[^5] and your data isn’t being tracked near constantly to serve you ads.

With this information I decided to try dual booting Linux alongside my existing windows installation on my laptop. Instead of taking the full leap to Linux, I put them both on my machine so if I had any issues come up using Linux, I could just quickly boot back into windows. I followed along with a couple videos that explained how to make sure that I don’t overwrite windows while installing ==fedora Linux==[^6], and after that it was pretty much just clicking continue a couple of times. The only issue that came up was when I would try to switch back to windows, I’d have [Bitlocker](https://en.wikipedia.org/wiki/BitLocker) pop up requiring I put in my key. That was a problem with windows and not Fedora, easily fixed by disabling Bitlocker.
